# PTP

PTP is a travel-safety companion for community incident reports, verified local guidance, trusted-contact alerts, group trips, and safety-aware directions.

## MVP documentation

- [MVP product plan](docs/MVP_PLAN.md)
- [Safety, privacy, and moderation requirements](docs/SAFETY_PRIVACY.md)

## MVP focus

The first version centers on reviewed community reports, official regional resources, trusted-contact safety alerts, and transparent route preferences. PTP does not guarantee safety and is not a replacement for local emergency services.
